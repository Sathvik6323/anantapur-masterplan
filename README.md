# Anantapur Master Plan — Interactive Web Map

Interactive Leaflet web map of the Ananthapuramu–Hindupur Master Plan area with an opacity slider for the raster overlay.

## Features

- Google Earth satellite basemap
- AHUDA master plan raster overlay with opacity control
- Zoom, pan, and full-screen map interaction
- Attribution credits for data sources and tools

## Opacity Slider

Use the slider in the top-right corner to adjust the raster overlay transparency (0–100%).

## Deploy to GitHub Pages

1. Push this folder's contents to your GitHub repository root
2. Go to **Settings → Pages**
3. Under **Build and deployment**, select branch `main` and folder `/ (root)`
4. Click **Save** — your map will be live at `https://<user>.github.io/<repo>/`
